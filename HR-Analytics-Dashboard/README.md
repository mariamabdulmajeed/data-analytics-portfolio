# HR Analytics Dashboard
 
## Project Overview
 
This project analyzes workforce data to understand employee attrition, demographics, and HR performance metrics.
 
## Tools Used
 
- SQL
- Power BI
- Excel
 
## Business Questions
 
1. What is the attrition rate?
2. Which departments have the highest turnover?
3. What is the average employee tenure?
4. Which factors may influence attrition?
 
## KPIs
 
- Total Employees
- Attrition Rate
- Average Salary
- Average Tenure
