# Sales Analytics Dashboard
 
## Project Overview
 
This project analyzes sales performance to identify trends, top-performing products, profitable regions, and opportunities for business growth.
 
## Tools Used
 
- SQL
- Power BI
- Excel
 
## Business Questions
 
1. Which products generate the highest revenue?
2. Which regions are most profitable?
3. What are the sales trends over time?
4. Which customers contribute the most revenue?
 
## Key Performance Indicators (KPIs)
 
- Total Sales
- Total Profit
- Profit Margin %
- Number of Orders
- Average Order Value
